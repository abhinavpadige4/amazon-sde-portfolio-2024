# Amazon SDE Portfolio

A modern, responsive portfolio website for an Amazon Software Development Engineer featuring a dark/light theme toggle, showcasing expertise in distributed systems and AWS.

## 🚀 Live Demo

[https://amazon-sde-portfolio-2024.vercel.app](https://amazon-sde-portfolio-2024.vercel.app)

## ✨ Features

- **Modern Dark/Light Theme** - Toggle between dark and light modes with system preference detection
- **Responsive Design** - Fully responsive layout for mobile, tablet, and desktop
- **Hero Section** - Prominent introduction with name and tagline
- **About Section** - Professional bio with statistics and profile image
- **Skills Section** - Visual representation of distributed systems and AWS expertise
- **Projects Section** - 4 featured projects with metrics, technologies, and screenshots
- **Experience Timeline** - Vertical timeline showing professional experience at Amazon
- **Contact Form** - Functional contact form (integrated with Formspree)
- **Smooth Animations** - Subtle animations and transitions for enhanced UX
- **Accessibility** - WCAG AA compliant with proper semantic HTML
- **Performance Optimized** - Fast loading times and efficient rendering

## 🛠️ Technologies Used

- **HTML5** - Semantic markup structure
- **CSS3** - CSS Variables, Flexbox/Grid, Animations
- **JavaScript (ES6+)** - Vanilla JS for interactivity
- **Font Awesome 6** - Icon library
- **Google Fonts** - Inter typography
- **Formspree** - Form backend service
- **GitHub Pages/Vercel** - Deployment platform

## 🎨 Design System

### Color Tokens

**Dark Theme:**
- Background: `#0D0D0D`
- Surface: `#1A1A1A`
- Primary: `#FF9900` (Amazon Orange)
- Accent: `#00E676` (Green)
- Text: `#E0E0E0`

**Light Theme:**
- Background: `#FFFFFF`
- Surface: `#F5F5F5`
- Primary: `#FB8C00`
- Accent: `#00C853`
- Text: `#212121`

### Typography
- Font Family: `'Inter', sans-serif`
- Weights: 300, 400, 500, 600, 700

### Spacing
- xs: 0.5rem
- sm: 1rem
- md: 1.5rem
- lg: 2rem
- xl: 3rem

## 🔧 Setup & Development

1. **Clone the repository**
   ```bash
   git clone https://github.com/abhinavpadige4/amazon-sde-portfolio-2024.git
   cd amazon-sde-portfolio-2024
   ```

2. **Open in browser**
   Simply open `index.html` in your preferred browser

3. **For development**
   - Modify files in `/css/` and `/js/` directories
   - Update assets in `/assets/` directory
   - Changes are reflected immediately

## 📱 Responsive Breakpoints

- **Mobile**: < 480px
- **Tablet**: 480px - 768px
- **Desktop**: > 768px
